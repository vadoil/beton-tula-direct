## Сайт по продаже бетона и ЖБИ в Туле — high-conversion landing

Одностраничный продающий сайт на русском языке для компании-поставщика бетона и ЖБИ. Цель — максимум заявок и звонков. Строгий, индустриальный, дорогой визуал «для строителей».

### Визуальная концепция

- **Палитра**: глубокий графит/антрацит как основа, белый/светло-серый фон секций, акцент — насыщенный янтарно-оранжевый (signal/safety) для CTA и ключевых акцентов. Ощущение бетона + строительной техники.
- **Типографика**: крупные плотные заголовки (Inter/Manrope, жирные начертания), читаемый body-текст, чёткая иерархия H1/H2/H3.
- **Стиль**: индустриальная сетка, толстые разделители, бетонные текстуры/паттерны очень дозированно, иконки lucide линейные.
- **CTA**: контрастные оранжевые кнопки, повторяются в каждом блоке.
- **Адаптив**: mobile-first, sticky-панель снизу на мобильном с кнопками «Позвонить» и «Заявка».

### Структура страницы (одна страница, плавная прокрутка)

1. **Шапка (sticky)** — логотип, навигация (Каталог бетона, ЖБИ, Доставка, Калькулятор, FAQ, Контакты), телефон крупно, кнопка «Заказать звонок».
2. **Hero** — заголовок «Бетон с доставкой по Туле и области. Точно в срок, с паспортом качества», подзаголовок с выгодами, две CTA-кнопки («Рассчитать стоимость», «Получить цену сегодня»), 4 быстрых преимущества иконками, компактная форма быстрой заявки (телефон + что нужно), плашка доверия «Работаем с частными и коммерческими объектами».
3. **Преимущества** — сетка 6–8 карточек с иконками: доставка по Туле и области, широкий выбор марок, полный каталог ЖБИ, оперативный расчёт, соблюдение сроков, контроль качества, удобная логистика, частные и оптовые заказы.
4. **Каталог бетона** — карточки типов (товарный бетон, раствор, пескобетон, для фундамента, для стяжки, для плит и перекрытий, для дорожных работ, для монолита). На каждой карточке — название, описание применения, преимущества, плашки марок (М100–М600), кнопки «Узнать цену» и «Заказать с доставкой». Табы/фильтр по марке.
5. **Каталог ЖБИ** — крупная сетка карточек: ФБС блоки, плиты перекрытия, перемычки, кольца колодезные, крышки и днища, дорожные плиты, лотки, сваи, бордюры, опорные элементы, фундаментные элементы, прочие ЖБИ. На карточке — назначение и две CTA («Запросить цену», «Оставить заявку»).
6. **Подбор материала под задачу** — продающий блок-навигатор: фундамент, отмостка, стяжка, монолит, перекрытия, дорожные работы, колодцы и инженерка. Большой CTA «Не знаете, что выбрать? Подберём бетон или ЖБИ под ваш объект».
7. **Доставка** — преимущества доставки + визуальная схема в 5 шагов (заявка → уточнение → расчёт → согласование → доставка на объект).
8. **Доверие** — блок триггеров: контроль качества, честный объём, соблюдение сроков, консультация по марке, физлица и организации, документы, понятные условия.
9. **Калькулятор / форма заявки** — крупная форма: тип (бетон/раствор/ЖБИ), марка или тип изделия, объём, адрес доставки, имя, телефон, комментарий. Кнопка «Получить расчёт стоимости». Валидация (zod), маска телефона, состояние «отправлено».
10. **FAQ** — аккордеон с 7 вопросами из брифа.
11. **Финальный CTA** — мощный экран на тёмном фоне: заголовок «Нужен бетон или ЖБИ в Туле? Рассчитаем стоимость и организуем доставку», форма + крупная кнопка, акцент на быстрый отклик.
12. **Footer** — контакты, телефон, адрес, режим работы, разделы, повторная кнопка связи, копирайт.
13. **Mobile sticky bar** — снизу на мобильном: «Позвонить» + «Оставить заявку».

### Тексты

Все тексты пишутся на русском, без канцелярита, конкретно и уверенно: упор на скорость, надёжность, точный объём, паспорт качества, доставку на объект, помощь с подбором марки. Заголовки SEO-ориентированы под запросы: «бетон в Туле», «купить бетон с доставкой Тула», «ЖБИ Тула», «бетонные изделия Тула», «заказать бетон Тула».

### Технические детали

- React + Vite + TypeScript + Tailwind, компоненты shadcn/ui (Button, Card, Accordion, Tabs, Input, Textarea, Select, Form, Dialog, Sonner для тостов).
- Дизайн-система: расширить `index.css` и `tailwind.config.ts` — добавить HSL-токены (graphite, concrete, signal-orange и т.д.), кастомные тени, радиусы, типографические утилиты. Никаких прямых цветов в компонентах — только токены.
- Иконки — `lucide-react`.
- Формы — `react-hook-form` + `zod` (валидация телефона, обязательных полей, длин), отправка пока имитируется (тост «Заявка отправлена, перезвоним в течение 15 минут») — позже легко подключить бекенд.
- Плавный скролл по якорям, sticky header, sticky mobile CTA bar.
- Структура файлов: `src/pages/Index.tsx` собирает секции из `src/components/sections/*` (Hero, Benefits, ConcreteCatalog, ZhbiCatalog, MaterialSelector, Delivery, Trust, CalculatorForm, Faq, FinalCta, Footer, Header, MobileStickyBar).
- SEO: обновить `index.html` (title, description, og-теги на русском), семантические теги (`<header>`, `<main>`, `<section>` с `aria-label`), H1 один на странице.
- Без бекенда на этом этапе (Lovable Cloud можно подключить позже для приёма заявок и хранения каталога).
- Адаптивность проверяется на брейкпоинтах sm/md/lg.

### Что НЕ делаем сейчас

- Реальную отправку заявок (только UI + тост-подтверждение).
- Внутренние страницы каталога (структура заложена, но генерируем только лендинг).
- Подключение CMS/БД.
